## 🧭 Overview

This e-book serves as a comprehensive textbook for the undergraduate course **977-114 Digital Logic and Design**, part of the *Digital Engineering International Program* at Prince of Songkla University.  
It introduces **digital system design**, **hardware description languages (HDL)**, and **FPGA prototyping** using **Verilog HDL**.

The book emphasizes a **practical, hands-on approach** that bridges theory, simulation, and real hardware implementation.

---

## ⚙️ Structure and Key Features

The book contains **10 chapters** and a **lab appendix** covering:

1. **Digital Design and FPGA** — Fundamentals, architectures, and design flow.  
2. **Fundamentals of Verilog HDL** — Syntax, modeling, simulation, and debugging.  
3. **Combinational Logic Design** — Boolean algebra, multiplexers, decoders, and adders.  
4. **Sequential Logic Design** — Flip-flops, counters, and clocking strategies.  
5. **Finite State Machines and Control** — Moore/Mealy FSMs and control applications.  
6. **Design for Synthesis and Timing** — RTL coding, STA, and optimization.  
7. **FPGA Architecture and Resources** — CLBs, DSPs, BRAMs, and routing networks.  
8. **FPGA Design Flow and Toolchains** — From HDL to bitstream programming.  
9. **System Design and IP Integration** — SoC design, IP cores, and verification.  
10. **Real-World FPGA Projects** — DSP, AI, motor control, and communication systems.

**Appendix A:** Includes **14 FPGA labs** — from logic gates to UART communication — with simulation and hardware results.

---

## 💡 Pedagogical Approach

- Structured examples with synthesizable Verilog code.  
- Testbenches and simulation workflows using **Xilinx Vivado**.  
- Synthesis and timing analysis for real hardware.  
- Design projects demonstrating **practical FPGA system design**.  
- End-of-chapter exercises and bibliographies for self-learning.
